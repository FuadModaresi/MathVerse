# MathVerse

MathVerse is an interactive graphing calculator and AI math tutor built with Next.js and Firebase Studio. It provides a dynamic and intuitive platform for students, educators, and math enthusiasts to visualize and understand mathematical functions.

---

## English

### Features

-   **Interactive 2D Graph:** Plot multiple functions on a single Cartesian plane.
-   **Dynamic Controls:** Pan by clicking and dragging, and zoom in/out for detailed analysis.
-   **Customizable Equations:**
    -   Add, edit, or remove functions easily.
    -   Change the color of each function's graph.
    -   Toggle the visibility of any function.
-   **AI-Powered Explanations:** Get a detailed, AI-generated explanation of the plotted functions, including analysis of slope, intercepts, and transformations.
-   **Virtual Math Keyboard:** Access common mathematical functions and symbols (`sin`, `cos`, `log`, `π`, etc.) with a single click.
-   **Light & Dark Mode:** Switch between themes for your viewing comfort.

### How to Use

1.  **Adding a Function:**
    -   Click the `+ Add` button to create a new input field for a function.

2.  **Entering an Equation:**
    -   Type a valid mathematical expression in the `f(x) =` input field. The variable must be `x`.
    -   The app supports standard operators (`+`, `-`, `*`, `/`), exponentiation (`^`), and a wide range of math functions (`sin(x)`, `cos(x)`, `log(x)`, `sqrt(x)`).

3.  **Interacting with the Graph:**
    -   **Pan:** Click and drag anywhere on the graph to move the view.
    -   **Zoom:** Use the `Zoom In` (+) and `Zoom Out` (-) buttons to change the view's scale.
    -   **Reset:** Click the `Reset` button to return the graph to its default position and zoom level.

4.  **Managing Functions:**
    -   **Change Color:** Click the color swatch next to an equation to open a color picker.
    -   **Toggle Visibility:** Click the `Eye` icon to show or hide a function on the graph.
    -   **Delete:** Click the `Trash` icon to remove a function.

5.  **Get an AI Explanation:**
    -   Once you have one or more visible functions plotted, click the `Explain with AI` button.
    -   A dialog box will appear with an AI-generated analysis of the functions.

## فارسی (Persian)

### ویژگی‌ها

-   **نمودار دو بعدی تعاملی:** چندین تابع را بر روی یک صفحه دکارتی رسم کنید.
-   **کنترل‌های پویا:** با کلیک و کشیدن نمودار را جابجا کنید و برای تحلیل دقیق‌تر، بزرگنمایی یا کوچکنمایی کنید.
-   **معادلات قابل تنظیم:**
    -   توابع را به راحتی اضافه، ویرایش یا حذف کنید.
    -   رنگ نمودار هر تابع را تغییر دهید.
    -   نمایش هر تابع را فعال یا غیرفعال کنید.
-   **توضیحات مبتنی بر هوش مصنوعی:** توضیحات دقیقی از توابع رسم شده، شامل تحلیل شیب، نقاط تقاطع و تبدیلات، توسط هوش مصنوعی دریافت کنید.
-   **صفحه کلید ریاضی مجازی:** با یک کلیک به توابع و نمادهای رایج ریاضی (`sin`, `cos`, `log`, `π` و غیره) دسترسی پیدا کنید.
-   **حالت روشن و تاریک:** برای راحتی بیشتر، بین تم‌های مختلف جابجا شوید.

### نحوه استفاده

۱. **افزودن تابع:**
    -   برای ایجاد یک فیلد ورودی جدید برای تابع، روی دکمه `+ Add` کلیک کنید.

۲. **وارد کردن معادله:**
    -   یک عبارت ریاضی معتبر را در فیلد ورودی `=f(x)` تایپ کنید. متغیر باید `x` باشد.
    -   برنامه از عملگرهای استاندارد (`+`, `-`, `*`, `/`)، توان (`^`) و طیف گسترده‌ای از توابع ریاضی (`sin(x)`, `cos(x)`, `log(x)`, `sqrt(x)`) پشتیبانی می‌کند.

۳. **تعامل با نمودار:**
    -   **جابجایی (Pan):** برای حرکت دادن نمای نمودار، در هر نقطه‌ای از آن کلیک کرده و بکشید.
    -   **بزرگنمایی (Zoom):** از دکمه‌های `Zoom In` (+) و `Zoom Out` (-) برای تغییر مقیاس نما استفاده کنید.
    -   **بازنشانی (Reset):** برای بازگرداندن نمودار به موقعیت و سطح بزرگنمایی پیش‌فرض، روی دکمه `Reset` کلیک کنید.

۴. **مدیریت توابع:**
    -   **تغییر رنگ:** برای باز کردن انتخابگر رنگ، روی نمونه رنگ کنار یک معادله کلیک کنید.
    -   **تغییر نمایش:** برای نمایش یا پنهان کردن یک تابع روی نمودار، روی آیکون `چشم` کلیک کنید.
    -   **حذف:** برای حذف یک تابع، روی آیکون `سطل زباله` کلیک کنید.

۵. **دریافت توضیحات هوش مصنوعی:**
    -   پس از رسم حداقل یک تابع قابل مشاهده، روی دکمه `Explain with AI` کلیک کنید.
    -   یک کادر محاوره‌ای با تحلیلی که توسط هوش مصنوعی تولید شده است، ظاهر می‌شود.
