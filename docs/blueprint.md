# **App Name**: MathVerse

## Core Features:

- Interactive Graphing Engine: Plots algebraic functions (linear, quadratic, polynomial, trigonometric, exponential, logarithmic) with real-time updates as the user edits the equation, plus zooming, dragging, and scaling capabilities. Includes optional grid, axis labels, intersection points, and slope display.
- Multi-Mode Smart Calculator: Offers Basic, Scientific, Algebra, Trigonometry, Fractions, and Complex numbers modes, providing step-by-step explanations for solving expressions, error detection, input validation, history log, and result copying.
- Custom Mathematical Keyboard: Includes symbols: π, e, √, ^, fractions, parentheses, sin/cos/tan, log/ln with a responsive layout and smooth input insertion.
- AI-Powered Graph Explanation Tool: Generates simple notes using AI to explain displayed graphs, including slope, intercepts, and turning points for polynomial functions; acts as a tool providing optional insights into transformation effects (shift, stretch, reflection).

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), symbolizing intellect and depth, complementing the educational focus.
- Background color: Very light gray (#F0F0F5), providing a clean, distraction-free backdrop that supports prolonged screen time.
- Accent color: Vivid magenta (#FF00FF), strategically used to highlight interactive elements and key functionalities, ensuring critical features grab user attention.
- Body and headline font: 'Inter', a sans-serif, chosen for its modern, neutral aesthetic and excellent legibility, ensuring ease of reading across all educational content. 
- Use clean, geometric icons to represent different mathematical functions and operations, aiding intuitive navigation.
- Emulate the chat-with-geogebra layout, adapting modern dark design and ensuring support for the Persian language. Maintain a student-friendly interface with a focus on providing clear access to each function.
- Subtle animations to indicate real-time graph updates and transitions between calculator modes, enhancing user engagement and comprehension without overwhelming.
